# 🛒 E-Commerce Sales & Customer Analytics Dashboard

An interactive **Power BI dashboard** designed to analyze e-commerce sales performance, customer behavior, product performance, and customer value.

The project transforms raw transaction data into meaningful business insights using **Python, Pandas, Power BI, and DAX**.

---

## 📊 Dashboard Overview

This dashboard provides an interactive view of the business through multiple analytical perspectives:

- 📈 Sales Performance
- 👥 Customer Analytics
- 🎯 RFM Analysis
- 🧩 Customer Segmentation
- 🛍️ Product & Category Performance
- 🔄 Returns Analysis
- ⭐ Customer Ratings
- 🏆 Top Customers & Products
- 📅 Sales Trends

---

## 🎯 Project Objective

The main objective of this project is to analyze e-commerce transaction data and answer important business questions such as:

- How are sales performing over time?
- Which products and categories generate the most sales?
- Who are the highest-value customers?
- How frequently do customers purchase?
- Which customers are at risk of becoming inactive?
- What are the main customer segments?
- What is the average order value?
- Which products have higher return rates?
- How do customer ratings vary across products and categories?

# 📈 Sales Analysis

The dashboard analyzes:

- Total Sales
- Total Orders
- Total Quantity
- Average Order Value
- Sales Trends
- Sales by Category
- Sales by Product
- Sales by Region
- Sales Performance over time

### Key KPIs

| KPI | Description |
|---|---|
| Total Sales | Total revenue generated |
| Total Orders | Number of unique orders |
| Total Quantity | Total products sold |
| Average Order Value | Average revenue per order |
| Return Rate | Percentage of returned transactions/products |
